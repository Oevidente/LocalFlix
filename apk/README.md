# CineLocal - APK Android

Nesta pasta ficam salvos os arquivos APK para instalação no Android (Smart TVs, TV Box e Celulares).

- **Versão Atual**: `v1.3.6`
- **Arquivo**: `CineLocal-v1.3.6.apk` (ou `CineLocal-debug.apk`)
- **PWA**: Também é possível instalar como Progressive Web App direto pelo navegador no Android ou PC através do botão de instalação na barra superior.
